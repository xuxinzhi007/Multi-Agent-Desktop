先说结论：现有 CLI 还不到「能正常使用」。最大的三个缺口是改动不能撤回、Ctrl+C 直接退出、回不到上次的会话。

以下结论来自读代码，本轮没有运行 CLI，也没有改任何文件。

第 6、9 条的具体问题：

权限记忆有洞：记忆只看命令的第一段。记住 ls 之后，ls && git push 的签名也是 ls，会直接放行。
输入文字等于拒绝：审批等待时，输入任何不是 y / a 的文字都被当成拒绝。
没有「总是」：只有「本次」和「本会话记住」。
豆包后端不受控：写死 always_allow，/mode 对它无效。
每次启动都新建会话：秒退也会留下一个空会话。
-resume 选错：取名单里第一个顶层会话，不看当前目录，也不看时间。
多进程互相覆盖：会话全在一个 agents.json 里，每个进程整文件写，没找到文件锁。两个终端或「桌面 + CLI」同时开会丢会话。
另有一条基线外的发现：CLI 启动时会把桌面那套一起拉起来（127.0.0.1:8780 的 HTTP 网关、计划调度、飞书同步），连 -h 也是。

二、三个岔路的立场
Git：同意直接改工作区、用检查点撤回、不自动提交。自动提交会污染你的历史；检查点存在数据目录，不进仓库。
自主程度：保留现在的默认档（文件编辑顺、命令要问、按命令族记忆），只修洞和改名。
多 Agent：主入口是当前对话。临时读写子任务已经符合，隔离子会话的「带回」放第三批。
三、分阶段方案
第 0 步：让验收有意义（不改产品行为）
为了：基线 13，以及「提交前跑 npm run verify」。
改什么：4 个失败测试改成用系统临时目录。其中 3 个共用的 testWorkDir 写死了 /tmp，第 4 个断言 /tmp/work。同时确认两件我没核实的事：这台机器能否跑 go test -race（需要 cgo），以及打包出的 exe 在 PowerShell 里是否带控制台。
不改会怎样：verify 在 Windows 上永远是红的，后面每一批都无法证明没改坏。
验收：PowerShell 里跑 npm run verify，如实记录哪一步过、哪一步不过。
第一批：达到「能正常使用」所必须的五件事
A. 入口与首次启动（基线 1、2、13）

改什么：
一个短命令（名字待你定），位置参数是任务而不是目录。
启动时检查：没模型就在终端里引导填厂商、Key、模型；目录过宽直接拦住并说明怎么办。
!命令 改走和模型同一套 shell（Windows 上是 PowerShell）。
CLI 模式不再启动网关、调度和飞书。
不改会怎样：新用户第一步就卡住，还得先装桌面端。
验收：清空模型配置，在任意仓库目录敲短命令，按提示填完后能直接交代任务；!git status 有输出；在用户主目录启动会被拦住。
B. 会话按项目续接（基线 9）

改什么：
发出第一条消息才建会话。
「继续上次」只在当前目录的会话里取最近一个，另给一个只列本目录的选择器。
退出时打印一行续接命令。
存盘时只合并本进程动过的会话。
不改会怎样：关掉终端就找不回上下文，开两个终端会互相覆盖。
验收：仓库 A 聊两句退出，按提示命令回来能看到历史。仓库 B 里「继续」不会拿到 A 的会话。两个终端各聊一轮后都退出，两边会话都在。
C. 中断与引导（基线 7）

改什么：
Ctrl+C 运行中只停这一轮，空闲时提示「再按一次退出」。
运行中输入的消息并入当前这一轮；后端已有这个能力，终端没接。
取消一律显示「已停止」。
不改会怎样：误按一次就丢掉整个现场，发现方向错了也只能干等。
验收：让它跑一个长任务，按一次 Ctrl+C 程序还在、显示已停止，再按才退出。运行中补一句「只改 X 文件」，它会照做。
D. 文件检查点与撤回（基线 8）

改什么：
每轮第一次写某个文件前存一份原文。
/diff 显示本会话真实改动内容，非 Git 目录也能用。
撤回可选「只撤对话 / 只撤文件 / 都撤」。
这一轮跑过命令时，明说「命令改的文件不在检查点里，用 Git 找回」。
不改会怎样：改坏了只能靠 git checkout，没提交过的内容直接丢。
验收：让它改两个文件，/diff 能看到具体行。撤回后文件内容与改之前逐字节一致。让它用命令删一个文件，撤回时能看到那句提示。
E. 权限修补与 -p 契约（基线 3、6）

改什么：
带连接符的命令逐段判断，git push 永不进记忆。
审批时必须明确按键，输入的文字不再当拒绝。
改正 auto 的说明文字。
豆包会话在状态栏标明「不受权限模式控制」。
-p 的审批提示改到 stderr；没有终端时直接拒绝并返回非零退出码。
不改会怎样：记住一条无害命令就可能放过一次推送；脚本里的输出被审批提示污染。
验收：记住 ls 后让它跑 ls; git push，仍会弹审批。短命令 -p "跑一下测试" > out.txt，out.txt 里只有答案。
