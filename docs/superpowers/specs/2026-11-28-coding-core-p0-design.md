# 编码核心 P0：替换阶梯、写入即诊断、地图按原话排序

**日期**: 2026-11-28

## 1. 为什么做

和 Cursor / Claude Code / Codex / Aider 比，这套循环差在三处，都落在 `internal/tool/builtin`：

1. `edit_file` 与 `apply_patch` 用 `strings.Count` 找锚点，差一个行尾空格、或文件是 CRLF 就整次失败，模型要再读一轮重贴。
2. 语法错误要等模型声称完成、调 `verify` 才暴露，中间已经继续改了几步。
3. `repo_map` 每个文件只取前 12 个声明、按关键词和修改时间排序，不带行号。用户点名的函数排在第 13 个之后就不在地图里。

参考实现是 Aider（Apache-2.0）的 `aider/coders/search_replace.py`（`flexible_search_and_replace`）、`aider/linter.py`、`aider/repomap.py`（`get_ranked_tags`）。只借算法，不引入依赖；审批、版本校验、审计、工作树都保持在写入之前。

## 2. 三刀

### 2.1 替换阶梯（`anchor.go`，`edit_file` 与 `apply_patch` 共用）

按顺序试，哪一档命中唯一一处就用哪一档：

| 档 | 忽略什么 | 写回去的内容 |
|---|---|---|
| 逐字节 | 无 | `newText` 原样（行为与改造前完全一致） |
| 换行符 | CRLF 与 LF 的差别，锚点可以从行中间开始 | `newText` 按文件的换行风格转换 |
| 行尾空白 | 再忽略每行末尾的空格与 tab，锚点必须对齐整行 | 同上 |
| 缩进偏移 | 再忽略整块统一多出或少掉的一段行首空白 | `newText` 每个非空行做同样的偏移 |

规则：

- 任何一档命中多处就停，整次拒绝、零写入，报出命中的行区间和原文。不继续放宽，也不替换第一处。
- 逐字节一档命中多处时沿用原来的报错（`appears N times`）。
- 放宽命中时，工具结果和审批卡都写明用了哪一档、命中第几行。
- 缩进偏移一档里，`newText` 无法做同样偏移（要去掉的前缀它没有）时按找不到处理。
- 不做 tab 与空格互转，不做模糊相似度匹配。这两种都可能把内容写到模型没看过的位置。

### 2.2 写入即诊断（`syntax.go`）

`write_file` / `edit_file` / `apply_patch` 写完 `.go` 文件后，用 `go/parser` 解析落盘内容。解析失败时在**同一次**工具结果后面附上最多 5 条 `文件:行:列: 原因`。

- 状态仍是成功：字节已经写下去了，多步编辑的中间态允许暂时不合法。
- 只查语法。类型、`go vet`、测试仍归 `verify`。
- 只做 Go。TS 没有标准库解析器，本轮不引入。

### 2.3 地图按原话排序（`repo_map.go`）

- 输出每个声明带行号：`  42: func Server.Handler()  // 注释`，模型可以直接带 `offset` 去读。
- `RepoMap.Request` 是这一轮用户的原话。从里面取标识符，声明名或路径段与之相等的文件排前面。
- `RepoMap.Scope` 是会话 id。本会话写过的文件加分（写入记录按会话隔离，空作用域不记）。
- 命中的声明先排到文件内的前面再截 12 个，不会因为排在后面被截掉。
- Go 仍用 `go/ast`，TS 仍是行扫描。不上 tree-sitter，不加 cgo，不建索引。

`prepareNativeLoop` 在装完内置工具后，用带 `Scope` 和 `Request` 的 `RepoMap` 覆盖同名注册。

## 3. 不做

- 收窄编码回合的工具表（笔记、飞书、建会话移出编码提示）：下一刀。
- gopls / tsserver：语法诊断不够用之后再评估。
- 逐字节命中时把 `newText` 的换行转成文件风格：这会改动现有主路径的输出，单独评估。

## 4. 验收

| 用例 | 期望 |
|---|---|
| CRLF 文件，锚点是 LF | 写入成功，文件仍全是 CRLF，结果写明「换行符」一档 |
| 文件行尾多空格 | 写入成功，结果写明「行尾空白」一档 |
| 锚点整体少一层缩进 | 写入成功，`newText` 补上同一层缩进 |
| 放宽后命中两处 | 拒绝，文件一个字节不变，报出两处行号 |
| `apply_patch` 一条放宽成功、另一条歧义 | 整批拒绝，两个文件都不变 |
| 写下的 Go 括号不配对 | 同一次结果里有 `文件:行:列` |
| 用户原话点名一个函数 | 含它的文件排第一，该声明不被 12 个上限截掉 |
| 本会话刚写过的文件 | 排在同分的其它文件前面；别的会话不受影响 |
