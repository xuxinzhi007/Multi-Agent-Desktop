## 3. 仍需优先处理（来自网关评审）

`docs/reviews/code-review-gateway-m3-2026-11-26.md` §4.1 的问题在收工时仍存在，优先看前两条：

1. **Broker send-on-closed panic**：`Publish` 释放锁后向订阅通道发送，`Unsubscribe` 关闭通道；并发断开 SSE 时可能 panic。建议发送与关闭共用同一把锁，或用 `done` 通道。
2. **`main.go` 的 `gw` 读写竞态**：`emit` 闭包读 `var gw`，主 goroutine 之后赋值；事件并发时是未同步读写。建议 `atomic.Pointer`，或在 Manager 启动前完成赋值。
3. Scheduler 全局限频 token 在任务限频失败前已扣减；`limiter.consume` 在 `s.mu` 外修改状态。
4. `PutFact` 重写事实时会把 `source_event_id` 置空，丢失来源。
5. `kind:"system"` 来自不可信请求体，可绕过 `mentionOnly` 策略。
6. `Host.Start` 失败后 `listenErr` 未在成功时清空；页面可能仍显示端口占用。
