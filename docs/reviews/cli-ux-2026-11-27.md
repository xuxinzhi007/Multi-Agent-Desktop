# CLI 体验改造：cwd 语义、布局、工具行（2026-11-27）

起因：用户贴出一张 CLI 截图，五个现象同时出现。逐条对着代码查下来，是两个独立问题叠在一起——
**会话模型要求显式目录，而 CLI 从不给**；**TUI 高度算错**。参考对象：`charmbracelet/crush`（同栈 Go + Bubble Tea）
与 `oschina/mothx`（MIT、同架构 Go + Bubble Tea + ACP + MCP）。

## 1. 现象 → 根因

| 现象 | 根因 |
|---|---|
| `/new` 后一说话就 `错误：这个会话还没有文件夹`，且重复两条 | `cmdNew` 走 `CreateInheriting("", name, "")`，`createWith` 不赋 `WorkDir`；`EffectiveWorkDir` 的设计是"没选就是空"。第一条消息在 `prepareNativeLoop` 被挡（`loop_backend.go` 的目录校验），错误事件与消息各渲一次 |
| 打 `/` 回车先报"没有这个指令"，再糊整张指令表 | 回车时先把输入框清空（`refreshMenu` 随之关掉菜单），`submit("/")` 落到 `execSlash` 的 default 分支，把 `slashHelp` 全量打出来 |
| 底部多行文字叠在一起 | `layout()` 用 `height - 3 - menuLines - 2`，而 `View()` 实际输出 `vpH + menuLines + input(3) + status(1)`；另外 `JoinVertical` 连接空菜单与组件自带的尾换行，又各多一行 |
| 状态栏被 `llama.cpp/qwen2.5-0.5b-instruct-q4_k_m.gguf` 挤爆 | `statusLine()` 拼全名，无截断、无 `~` 缩略、不显示目录 |
| 启动就"还没有会话，用 /new 新建" | `pickHeadlessAgent` 无 `-agent` 时要求已有会话 |

## 2. 改法（对齐 claude/codex/crush 的目录语义）

- `parseCLIArgs`：`-headless`、`-agent`、`-C/--cd`、`-p/--prompt`、`-m/--model`、`-resume`、`-h`；**位置参数当目录**。
- 启动即取 `-C` 或 `os.Getwd()`，`mgr.SetWorkDir(cwd)`，再 `ensureCLIAgent(...)` **按 cwd 新建会话**（不再抓 `list[0]`，避免一启动就接进昨天的上下文）。`-resume` 才接最近的。
- `cliModel` 加 `cwd`，`/new` 建完立刻 `SetAgentWorkDir`；新增 `/cd [路径]`（会话、shell、审批根一起走）。
- `layout()` 改成 `vpH = height - input(3) - status(1) - menuLines`；`View()` 只拼非空块并去掉各块尾换行。
- `statusLine()`：`~/proj  Agent 21  qwen2.5-0.5b  idle` + 右侧 `/ 指令  ctrl+c 退出`，按显示宽度截断（中文算 2 列）。
- 工具行：`→ bash  npm test` 起一行，`end` 时补 `✓ 1.2s` / `✗ 失败原因`；`diff` 字段非空时跟一段着色的 unified diff（前 20 行，超出给"还有 N 行"）。
- `/` 单独回车 → 打指令清单；未知指令只一行 `未知指令 xxx，/help 看全部`。
- 同一句 `agent.error` 只打一次（`lastErr` 去重）。
- TUI 启动时把 `log` 重定向到 `$TMPDIR/mad-cli.log`：alt-screen 下任何 `log.Printf`（飞书拉群、网关端口占用）都会插进画面。
- `-p` 一次性模式：走到 `RunPrompt` 打印结果就退出；`-m` 支持序号 / provider / provider/model，并在连接缺 `model` 时明确报错。

## 3. 验收

- `cli_tui_ux_test.go` 13 条：参数解析（含位置参数当目录）、`ensureCLIAgent` 新建/接管、`/new` 带目录、`/` 只给清单、未知指令一行、模型短名、`fitWidth` 宽字符、`renderDiff` 截断、`humanDuration`、**`View()` 行数严格等于终端高度**（80×24 / 100×30 / 60×16 与菜单展开）。
- 实跑（真 pty，`script` 抓屏）：

```
当前会话 Agent 21（/tmp/mad-cli-demo）
输入消息开始，输入 / 列出指令。

>
>
>

/tmp/mad-cli-demo  Agent 21  qwen2.5-0.5b-instruct-q4_k_m  idle        / 指令  ctrl+c 退出
```

- 回归：`go test . ./internal/tool/... ./internal/loop ./internal/config ./internal/mcp ./internal/gateway` 全绿。
