    Spec

    侧边栏设计规范

    表面

    • 底：#070b10，顶部两团低透明度光晕，不做大面积纯平色。
    • 卡片：slate-900/80，1px white/10，圆角 16。
    • 思考进行中才加脉冲光晕。结束后光晕停，卡片可折叠。

    四类区块

    1. 用户提问靠右，浅色字在深卡片上，时间戳独立一列。
    2. 思考独白默认收起。展开后正文 padding-top: 12px，滚动容器不包住第一行的上沿。
    3. 工具调用先给摘要：条数、重复目录、脱敏处数。点开才看每条命令。
    4. 最终回答独占一张卡片，流式时末尾保留插入光标。

    脱敏

    匹配 Bearer、sk-、api_key=。展示保留类型和末四位，例如 Bearer ••••c2e9。展开详情不还原原文。

    折叠

    连续相同的 cd 合成一条「进入目录 × N」。其他命令各自保留，长输出默认三行，点「展开输出」再看完。
