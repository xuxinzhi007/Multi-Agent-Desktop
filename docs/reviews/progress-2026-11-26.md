## 4. 验收现状

### CI 失败（run 45820980988，job 139912841778，HEAD `2c9bdb8`）

`go test -short ./...` 跑 10m14s 后 exit 1：

| 包 | 结果 | 证据 |
|---|---|---|
| `internal/agent` | **FAIL 600s 超时** | `TestExtraDirsSurviveRoundTrip` 卡 9m44s，栈在 `drainTest → WaitWorkers`，一堆 worker 停在 `workerLoop` 的 select |
| `internal/scheduler` | **FAIL** | `TestServiceCronDue: 07:30 应到期执行，runs=0` |
| 其余 25 包 | 绿 | root 45.5s、llm 122.2s、tool/builtin 2.2s… |

**根因 1：会话被装载两次。** `SetStore` 内部已经 `Load()`，测试 `m2.SetStore(...)` 后又显式 `m2.Load()`。`Load` 不做去重，同一个 ID 建出两个 worker；第二个覆盖 `m.agents`，第一个再也没人 `close(done)`，`WaitWorkers` 永远等不到零。已本地复现：`order=[a1 a1]`。

修法（已随 `711d40f` 提交，尚未 push）：`Load` 跳过 `saved.ID == ""` 和已存在的 ID；新增 `internal/agent/load_idempotent_test.go` 作为回归。验证：`go test -short ./internal/agent` **181.5s 绿**（原来必然 600s 超时）；在 `711d40f` 树上复跑 `TestExtraDirsSurviveRoundTrip` + 新回归，0.63s 绿。

**根因 2：默认静默时段吞掉 07:30。** 默认 quiet 是 23:00–08:00，按**本地时区**判断；CI runner 是 UTC，fake clock 的 07:30 就是本地 07:30，于是 `evaluate` 返回 `quiet`，`runs=0`。本地 `TZ=UTC` 可复现。

修法（已随 `711d40f` 提交，尚未 push）：该用例只测 cron 到期，先 `svc.cfg.Quiet = QuietWindow{12,12}` 关掉静默。验证：`TZ=UTC go test -short ./internal/scheduler` 0.66s 绿。

**还留一个产品问题**：用户显式排 07:30 的晨报，默认会被 23–08 静默吞掉，且界面只显示「静默」不提醒。要么把默认静默改成用户可关，要么在创建任务时对落在静默区的 cron 给出警告——需要拍板，不要用改测试掩盖。

其他日志：`auto worktree ... 这个文件夹不是 git 仓库` ×4 是 `SetAgentWorkDir` 默认隔离在测试临时目录里的正常降级，不致命，但会污染 CI 输出。
